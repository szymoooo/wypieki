WYPIEKI ANNY — strona promocyjna

1. Otwórz plik index.html w przeglądarce.
2. Wszystkie zdjęcia są w folderze assets.
3. Strona działa bez instalowania czegokolwiek i jest responsywna.
4. Formularz kontaktowy jest demonstracyjny. Aby go podłączyć, potrzebne będą dane kontaktowe Ani lub wybrana usługa/formularz.

Najłatwiejsze miejsca do zmiany:
- teksty: bezpośrednio w index.html
- numer telefonu / Instagram / Facebook: sekcja „Kontakt”
- zdjęcia: folder assets
